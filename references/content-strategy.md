# 内容策略

## 目标

用器物照片讲宋代生活与东方审美，让用户先获得知识和审美认同，再自然认识京鸿汝窑。内容应像文化编辑，而不是商品详情页。

## 选题路由

根据器物选择最自然的文化入口：

| 器物或视觉特征 | 优先文化入口 | 避免的生硬入口 |
|---|---|---|
| 茶壶、茶盏、建水、茶叶罐 | 宋人茶事、点茶秩序、涤器、茶席陈设 | 只列容量、出汤、密封性 |
| 香炉、炉式杯 | 宋人四雅、焚香、仿古、礼器日用化 | 只讲雕刻难度或烧成参数 |
| 莲花、花口、瑞兽、竹节 | 宋代自然观、吉祥母题、文人品格 | 只说造型可爱、纹样好看 |
| 月白、天青、粉青、豆绿 | 宋代色彩克制、素以为绚、一色做到极致 | 色卡式堆砌或夸张“绝美” |
| 柴烧、裸烧、手捏、窑变 | 不统一之美、火与土的偶然、手作微差 | 把瑕疵包装成神秘玄学 |
| 古器复刻 | 宋代仿古、礼器转为日用、器形比例 | 无证据声称“博物馆同款” |
| 现代器形 | 宋瓷审美如何进入现代生活 | 冒充宋代原型 |

## 标题公式

- 为什么宋人……也那么……？
- 宋瓷的……，为什么那么高级？
- 古器为什么越……，越耐看？
- 一件日用器，为什么能被记住千年？
- 宋人的茶席，为什么容不下……？
- 最高级的颜色，为什么几乎不用颜色？
- 器物上的……，为什么不只是装饰？

标题应包含可被搜索的核心词，如宋代审美、宋瓷、汝窑、茶席、焚香、月白釉、天青釉、建水、香炉。标题不是关键词清单，正文再自然覆盖长尾词。

## 一套图册的叙事比例

- 0–40%：文化问题、时代语境、史料证据；
- 40–65%：解释色彩、器形、空间、秩序或使用方式；
- 65–90%：器物软植入，出现京鸿汝窑和真实工艺；
- 90–100%：生活感受、审美收束或收藏理由。

产品页写具体而克制：器名、釉色、工艺、容量、器形或使用场景。避免“闭眼入”“高级感拉满”“提升品位”等商业腔。

## 正文结构

以用户确认的《宋人的茶席，为什么容不下一点凌乱？》为正文深度与语气基准。写成有起承转合、能独立阅读的多段文章；图片文字负责提炼，发布正文负责展开，不把逐页短句直接拼接成正文。

1. 用一个具体的文化问题开篇，先交代古人的生活场景和行为细节，让读者理解问题为何值得谈。
2. 引入至少一项与主题直接相关、可核验的文献、画作或馆藏。写出来源名称、作品或器物名称、画面或记载中的具体细节，再解释这些细节能说明什么；避免只罗列机构名或堆砌史料。
3. 从证据中提炼审美或生活秩序，保持叙述性与画面感，让知识自然推动观点，而非空泛地重复“克制”“高级”“温润”。
4. 由古代行为、器物功能或审美原则过渡到今天的使用场景，再引出商品。若现代名称、器形或用途与古代不同，像“建水”为当代茶席称呼那样明确说清，不硬认作宋代原名或原器。
5. 后段写京鸿汝窑的具体作品：只写已由照片、文件名或用户确认的器形、釉色、工艺与用法，并说明它如何回应前文的文化问题；避免连续罗列卖点。
6. 用一段有余味的生活观察收束，再以自然口吻署名“这里是京鸿汝窑，主理人张阁阁”。署名可随文章语气微调，不强制使用生硬的固定短句。

正文要有与所引史料相称的细节和篇幅，读起来像一篇文化随笔。引用应准确归属，产品应晚于文化内容出现；别用未经证实的典故填充篇幅。不同器物沿用这种写法和深度，不机械套用同一个例子、同一段落数或同一史料。

## 事实边界

- “汝窑为魁”“雨过天青”等常见说法也要查来源与语境，不能用网络转述替代考证。
- “宋代五大名窑”是后世归纳时，应避免写成宋人当时的官方排名。
- “博物馆同款”必须有可对应器形或藏品资料；否则写“取意于”“参考古器比例”。
- 视觉判断只能写“画面可见”“从照片看”；胎、釉配方、烧成温度等必须来自用户标签或可靠资料。

## 优先资料源

- 故宫博物院：https://www.dpm.org.cn/
- 中国国家博物馆：https://www.chnmuseum.cn/
- 地方博物馆、考古研究院和大学博物馆官方站点；
- 正式学术论文、展览图录和馆藏数据库。

每套文案末尾保留“内容核验所用资料（运营留档）”，便于后续复查，不把长链接直接放到图片正文中。
