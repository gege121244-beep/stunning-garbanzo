# 京鸿汝窑小红书图片知识卡制作

这是京鸿汝窑的小红书内容生产工作流。它把已经分类、命名的汝瓷与陶瓷照片，整理为可直接发布的知识型种草图册、逐页文字、小红书正文、搜索词与资料来源。

核心原则：先讲宋代文化、生活方式与审美知识，再让当代器物自然出现；保留原照片的器物造型、构图与色调，不把内容做成商品详情页。

## 工作流能力

- 盘点照片目录并按产品组归类；
- 根据图片内容重新选择适合的文化选题；
- 生成图册逐页文案与小红书发布正文；
- 在原图上排版，不裁剪、不重绘、不改变商品与底色；
- 统一京鸿汝窑品牌规则，同时让每页排版具有变化；
- 校验图片数量、输出尺寸、品牌文字和可读性；
- 用户升级要求后，同步更新 Skill 与远程仓库。

## 目录

- `SKILL.md`：主工作流与硬约束；
- `references/content-strategy.md`：选题、文化科普与软植入方法；
- `references/brand-and-visual-guide.md`：图片排版、字体、颗粒感与品牌规则；
- `references/manifest-schema.md`：批量制图清单格式；
- `scripts/`：照片盘点、图册渲染与交付校验脚本；
- `agents/openai.yaml`：Skill 展示配置。
